## 4.1 三层情绪架构（神经科学驱动）

```
输入(audio/text + 语速)
  ├─ Layer 0: 杏仁核（信号检测，LeDoux 1996 双通路低通路）
  │    → {tense, orient, approach, relax}   半衰期 0.3-2.5s（第一反应）
  │
  ├─ Layer 1: 皮层（embedding 语义检测，LeDoux 高通路）
  │    → {angry, sad, happy, ...}  Ekman 7 基本情绪 + neutral
  │    半衰期 40-90s（EDM 2015）/ 75-90min（Nature 2018）
  │
  ├─ Layer 2: VAD 累积（说话者→听者情绪感染）
  │    注意力分配衰减模型（Li 2017）+ 对立过程理论（Solomon 1974）
  │
  └─ 映射: VAD → FACS 参数 → Live2D 表情
```

### Layer 0 杏仁核（第一反应，12-74ms）

**来源**：LeDoux (1996) 双通路理论（低通路：丘脑→杏仁核，粗糙但即时）

| 信号特征 | 反应 | 时间 |
|----------|------|------|
| 激烈/攻击性 | tense（绷紧/警戒） | 12-50ms |
| 柔和/温暖 | relax（放松/开放） | 12-50ms |
| 新异/意外 | orient（聚焦/歪头） | 12-50ms |
| 悲伤 | approach（前倾/关切） | 50-150ms |

**检测方式**：sentence-transformer 语义匹配（gte-base-zh，768维）
- 原型：手写 42 句/类（**用户说话视角**，不是 AI 回应视角——检测的是对方说的话）
- 匹配：余弦距离 → softmax ×5
- 半衰期：tense 0.3s / orient 2.5s / approach 1.0s / relax 2.0s（startle reflex + orienting response 研究）

### Layer 1 皮层（理解后情绪）

**来源**：Hatfield 情绪感染理论(1992) + 评价理论(Lazarus 1991)

**检测方式**：embedding 语义匹配
- 原型：TIX007/chinese-sentiment 标注（joy/sad/anger/fear/surprise 各 100+ 句）+ 手写 disgust/contempt/neutral，共 428 句 8 分类
- 匹配：余弦 → softmax ×5 → ×长度置信度 min(字长/10, 1.0)
- **75% 阈值过滤**：强度 ≥ max×0.75 的情绪才进入听者映射（2026-07-27）

### Layer 2 VAD 累积（说话者→听者）

- **SPEAKER_TO_LISTENER 映射**：说话者情绪 → 听者感受（Hatfield 情绪感染）
- **注意力分配衰减**（Li 2017）：每帧找最强情绪 champion，champion 正常半衰期衰减，其他通道 ×4 加速衰减（"注意力被抢"）
- **自然半衰期表**（少女 8-12 岁版）：hurt/sad 15min、angry 5min、scared 45s、happy 10min、shy 3min…
- 先衰减旧值再累加新信号（同帧新信号不被衰减）
- 杏仁核 INC=1.0 满强度、皮层 INC=0.3 渐进

## 4.2 方向检测（你说我 / 你说别人）

**问题**：同一情绪指向不同对象，听者反应完全不同：
- "你笨蛋" → 冲我来的 → scared+hurt（反传染）
- "他好烦" → 吐槽别人 → contempt+amused（共享八卦）
- "我好难过" → 自述 → care+sad（共情）

**方法**：embedding 语义匹配（复用 gte-base-zh），手写两组原型：
- ABOUT_YOU（22句）：你笨蛋/你好可爱/你给我滚…
- ABOUT_OTHER（30句）：我好难过/他好烦/你觉得他怎么样…

测试 24/24 全对。**ABOUT_YOU → ATTACK 映射（反传染），ABOUT_OTHER → NORMAL 映射（identity 传染）**。

### 双路映射（2026-07-24 修正）

- **ABOUT_OTHER**：identity 映射——说话者什么情绪，听者就什么情绪（衰减由系数控制）
- **ABOUT_YOU**：反传染框架（Hatfield 反传染 + 愤怒冰山理论）

## 4.3 五组情绪映射体系（2026-08-08 定稿）

**核心设计**：不做映射表，键=我的情绪、1:1 进 VAD、单一归属不叠加。**输入来源 = 首级分类**：

```
LLM 回复线（18768/output → output_engine）→ 硬币说的 → 三选一
  classify_subject: 我说我 / 我说你 / 我说别人

ASR 输入线（18768/facs → facs_server）→ 别人说的 → 二选一
  is_about_you: 你说我 / 你说别人
```

| 场景 | 检测原型 | 进 VAD | 状态 |
|---|---|---|---|
| 输入侧·你说我 | told-me（9类） | 1:1 无映射表 | ✅ |
| 输入侧·你说别人 | 老8类 | SPK_TO_L_NORMAL 传染 | ✅ |
| 输出侧·我说我 | self-self（9类） | 1:1 out_me×1.8 | ✅ |
| 输出侧·我说你 | i-to-you（9类） | 1:1 out_you×0.8 | ✅ |
| 输出侧·我说别人 | — | SPK_OUT_OTHER / dist | ✅ |

三组新原型文件：`self_self.py` / `i_to_you.py` / `told_me.py`（各 9 类，心理学审校）。

## 4.4 VAD → FACS → Live2D 映射

### 情绪可见阈值（Calvo 2016）

| 情绪 | 可识别最低强度 |
|------|:--:|
| happy | 20%（最容易上脸） |
| sad/angry/surprise/disgust | 40% |
| fear | 50%（最难） |

### 非线性映射（Vision Research 2020）

```
AU_strength = sigmoid(k × (VAD - threshold))    k=12
```

### 卡通放大（Mäkäräinen 2014 + CHI 2025）

- 真实度越低 → 需越大幅度传达同样情绪
- 卡通脸：真人 150-200%
- 上半脸（眉/眼）可放大 1.5-2.0×，下半脸（嘴）谨慎（150% 恐怖谷边缘）

### 完整映射表（13 通道）

13 个 VAD 通道全部完成 Live2D 参数映射（happy/sad/angry/surprised/scared/hurt/worried/contempt/shy/care/orient/tense/approach）。×3 值为 Ekman 最小可识别表情的 3 倍，hurt/worried/contempt/shy 再 ×2（表演级）。

### 特殊动画

- **恐惧眼珠抖动**：每 150ms 随机 ±0.3
- **轻蔑眼睛状态机**：翻白眼(0.7-1.5s) ↔ 偷瞄(0.3s) ↔ 闭眼(2.2s)，连续偷瞄2次强制闭眼

### ⚠️ 参数方向（此模型非标准）

```
ParamAngleX + = 左转（标准是低头）
ParamAngleY + = 抬头（标准是左转）
ParamAngleZ + = 左歪（标准是右歪）
ParamBodyAngleX/Y 同理互换
```

## 4.5 前端 2D（puppet_live2d_v2.html）

**服务**：vad_bridge.py（18769 HTML+WS / 18770 API）

### 接收链

```
WS 接收 {type:'vad_status', mode, emotion, ratio} / {type:'emotion', cmd, arg}
  → setEmotion + VAD 面部插值（neutral + (emotion-neutral) × ratio）
  → 表情动作 playEmote / 弹簧系统过渡
```

### 表情动作系统（[TOOL:表情] 驱动）

6 组表情动作：认真(3.45s) / wink 4变体(2.02s) / 开心左右(3s) / spin左右(1.2s) / 转头左右(6s，含轻蔑状态机) / 担心左右(5s)
- phases 结构 {params, kc, dur}，弹簧过渡（`_emitTarget` 追踪 + PARAM_SPRINGS 物理）
- 头部快（k55）身体慢（k35）——头快身慢 = 活人感

### 18 组待机动作系统（2026-08-08）

模仿 neuro-sama "幅度大 + 非周期 + 有意图" 的待机动作（脱口秀演员风格）：

- `IDLE_SEQ`：18 组（吐槽摇头/俏皮歪头/扫视全场/强调前探/无奈耸肩/得意后仰/边说边晃/疑问侧头/思考/惊吓/害羞/打哈欠/假装生气/大笑/僵住/探头/歪头杀/无语）
- 每拍 {t:毫秒, params:delta目标}，身体幅度×2（2D 经验）
- **二阶弹簧**过渡（质量-弹簧-阻尼：force=k(target-pos)-c×vel，带过冲），非一阶平滑
- **delta 叠加**：加在 _renderParams 上，不覆盖 VAD 情绪基线
- 调度：3-8s 随机触发，仅待机（非说话）；默认开，独立开关按钮（🎭 待机动作 / ✨ 微动作）
- 时序依据真实研究：转头 30°≈0.5s（Frontiers）、点头单次 0.27s（九州大学）、身体 0.2-0.5Hz 低频

### 页面体验优化

- 🎮 开始测试按钮（toggle 展开/收起测试面板）
- 🎧 VAD 徽章（默认收起）
