> ASR：麦克风 → 流式识别 → 写桥进管线

## 5.1 ASR 听觉编码器（18686 + 桥 18680-18685）

**文件**：`asr+2d8.2确认/mic_vad_asr_streaming_vad.py` | 启动：`--threshold 300`

### 数据流

```
麦克风（WSLg PulseServer）
  ↓ parec 管道（绕过 PortAudio）
int16 → 能量 VAD 检测
  ↓ 说话中
paraformer-streaming 流式识别（每 600ms 取 final_text 全量）
  ├─ 说话中 → POST 18768/facs（全量文字，表情检测）
  ├─ 沉默中 → POST 18768/silent（衰减）
  └─ 说完了 → POST 18771/text（给 LLM）
```

### WSL2 音频通路

- WSLg PulseServer → parec → python subprocess 管道 → int16 numpy
- 自带桥 18680-18685（管线内建）+ 管理页 18686

### ASR 训练实验（asr训练/，离线）

Fun-ASR-Nano-2512（Qwen3-0.6B LLM + 音频编码器）：
- 提取 LLM 权重（model.pt 去掉 `llm.` 前缀 → 新建 Qwen3-0.6B）
- 训练数据：200 条合成 + TTS 50 条 + ESC-50 事件音效
- audio_embeds pad 到固定长度 218，labels 音频部分 -100
- SFT + GRPO（golden×20/sampled×0.01）均实现

## 5.2 TTS 语音合成（8000）

**文件**：`tts训练/tts_server.py` | 文档：`tts训练/README_TTS服务.md` | 环境：conda vllm
**模型**：CosyVoice2-0.5B（vllm 加速，RTF 0.13，首包 ~0.9s）

### 声线配置（混合声线）

```python
VOICE_CONF = {
    'furina_mona_50': {'alpha': 0.5, 'prompt': 'furina', 'pitch': 150},  # 默认：芙5:5莫 +150
    'furina':         {'alpha': 1.0, 'prompt': 'furina', 'pitch': 150},
    'mona':           {'alpha': 0.0, 'prompt': 'mona',   'pitch': 150},
}
```

- `alpha`：芙宁娜 embedding 占比（音色可插值——**音色 vs 韵律解耦**：speech token 承载内容+韵律，音色由 192 维 spk embedding 经 Flow 注入，连续空间可混合）
- `pitch`：sox pitch 变调 +150（"夹子音/偏高"听感，已定档）

### API

| 端点 | 功能 |
|------|------|
| `POST /api/tts` | 完整合成 → wav（X-Duration / X-Voice 头） |
| `POST /api/tts_stream` | 流式 SSE：`{start_ms, audio(base64)}` 逐 chunk + `{done}`（**口型同步预留**） |
| `GET /api/voices` | 声线列表 |
| `GET /` | 简易 UI |

### 管线接入（表达队列）

```
回复文本 → POST /api/queue_text（SSE 推词）→ 页面自动填框 → synth() → 播放
  → 播放完 POST 桥 /text {source:tts_done} → 消费者清桥 pop 下一个
```

### 微调为何挂起

微调训练的是韵律（token 层），需求是音色（embedding 层）——zero-shot + emb_mix 已满足，SFT 留作韵律优化。
