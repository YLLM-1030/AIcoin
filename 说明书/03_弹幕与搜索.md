## 3.1 弹幕采集（BLC 开放平台）

**文件**：`输入中心/弹幕接收/blc_collector.py`（桥 19000）+ `BLC管线架构.md`
**架构**：B站开放平台 WebSocket（非第三方库）

```
B站开放平台 API → POST /v2/app/start（身份码+app_id）→ {wss_link, auth_body, game_id}
  ↓
WebSocket 连 B站弹幕服务器
  ├─ 收 DANMU_MSG / SUPER_CHAT_MESSAGE / SEND_GIFT
  ├─ 格式化为数组 [avatar, timestamp, authorName, authorType, content, ...]
  └─ 逐行追加到桥 _store['弹幕']
```

**读后清空（wait 哨兵）**：消费者（danmaku_server）每 0.5s `GET /take`（原子"返回内容+置wait"），读到 wait = 无新消息。单消费者天然不重复、断线零成本。

## 3.2 弹幕打分器（scorer.py）

**架构文档**：`弹幕接收/架构说明.md`
**目标**：给每条弹幕打 0-1"回复欲望分"，决定秒回/攒批回/丢弃。

### 启发式特征（10 正向 + 5 负向，全部来自实证论文）

| 特征 | 分值 | 论文 |
|------|------|------|
| 基线话痨 | +0.08 | VTuber 人格设定 |
| 含问号 ? | +0.25 | FlirtGen: 15,000条, 问题 5.4x 回复率 |
| 疑问语气词 | +0.12 | 同上 |
| 脑洞/假想 | +0.15 | FlirtGen: 假想问题 77% 回复率 |
| 偏好站队 | +0.12 | FlirtGen: 偏好问题 70% 回复率 |
| 不同意见 | +0.12 | Chen et al.: 1,559条 logistic 回归 |
| 第二人称 | +0.08 | Library Hi Tech: 1,968条语言学分析 |
| 正面情绪 | +0.05 | 同上 |
| 叫名字 | +0.25 | addressee 检测, 跟问号同权重 |
| 赞美 | +0.12 | AI VTuber 专属 |
| 问候 | +0.08 | AI VTuber 专属 |
| 纯垃圾 | -0.30 | 666/hhh/草/… |
| 纯emoji | -0.20 | 无信息量 |
| 太短(<3字) | -0.10 | 难接话 |
| 纯陈述 | -0.12 | FlirtGen: 陈述仅15%回复率 |
| 太长(>100字) | -0.05 | 认知负荷 |

### 三阈值总分架构（已锁定 v2）

```
弹幕进入 → scorer打分(0-1) →
  ├─ 分 ≥ 秒发阈值(0.30) → 🔫秒回（弹夹+本条一起发射，清空已存）
  ├─ 丢弃阈值(0.11) ≤ 分 < 秒发阈值 → 进已存(弹夹)
  │   └─ 已存总分 ≥ 组合阈值 → 📤自动发射全部
  └─ 分 < 丢弃阈值 → 🗑丢弃
```

- 阈值页面可动态编辑，持久化 dm_config.json
- 发射目标 = 输出桥（当前 18008）
- 688 条真实数据测试：秒回 10.5%、进弹夹 1.7%、丢弃 87.8%

### addressee 权重（暂关闭）

| 对谁说 | 系数 | 话轮规则 |
|--------|------|----------|
| @me | ×1.0 | Sacks规则1: 被指定→必须回应 |
| @group | ×0.7 | 群体含我 |
| @self | ×0.5 | 氛围，可选插嘴 |
| @others | ×0.2 | 跟别人说，一般不理 |

### 为什么还没用动态阈值

论文：群聊回复概率 R ∝ 1/(1+N/k)。缺硬币本人开播实测数据 → 计划：固定阈值跑通 → 记录{分数, 回了没} → 拟合 R(N) → 替换动态阈值。

## 3.3 搜索工具（18775）

**文件**：`输入中心/搜索工具/search_server.py` + `web_search.py` | 架构文档：`搜索工具/架构说明.md`

### API

| 端点 | 方法 | 功能 |
|------|------|------|
| `/` | GET | 搜索页面 |
| `/api/search` | POST | 执行搜索（秘塔/DeepSeek 可切换） |
| `/api/search_history` | GET | 手动搜索历史 |
| `/api/queue_search` | POST | 管线推送搜索词（SSE 到页面） |
| `/api/queue_sse` | GET | SSE 长连接 |

### 搜索引擎

| 引擎 | 实现 | 说明 |
|------|------|------|
| 秘塔 | `/api/v1/chat/completions` conciseSnippet | key 内置 |
| DeepSeek | api.deepseek.com | 可编辑提示词，key 内置 |

### 管线接入

```
管线执行队列"搜索"任务 → POST /api/queue_search {"query":arg} → SSE 推词
  → 页面自动搜索 → 结果上桥 + done 上桥
  → 消费者轮询 EXEC_BRIDGE_PORT(18003) → tts_done=done → pop
  → 工具返回模块配 endpoint=结果桥 → prompt 自动注入搜索结果
```
