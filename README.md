# 迷你硬币 (MiniCoin) — 全自研 AI 主播系统

> 一个人 + AI 协作 2.5 个月，从零手搓的 B 站 AI 主播：本地 8B 模型实时驱动，傲娇雌小鬼人格，全链路自研——模型自己训、情绪自己研究、管线自己写。

---

## 一句话定位

不是「套一个 GPT + 一个 TTS」。而是一套**分层流水线**：感知层（听/看/读）→ 认知层（8B 微调主脑）→ 表达层（TTS + Live2D 演绎），全部在消费级显卡（RTX 3090 Ti 24GB）上本地运行、一键拉起。

---

## 三层架构

| 层 | 职责 | 关键实现 |
|----|------|---------|
| **感知层** | 听 / 看 / 读 | ASR 流式（mic_vad_asr_streaming_vad）、视觉（Qwen2.5-VL 占位）、弹幕采集（B站开放平台 WS） |
| **认知层** | 想 | Qwen3-8B 微调主脑（llama-server :8080），12 服务中的「大脑」 |
| **表达层** | 说 / 演 | TTS（edge-tts / CosyVoice2）+ Live2D 皮套（面部/肢体/表情动作） |

## 主数据流

```
弹幕 / 麦克风
  → 写桥（POST /text）
  → 管线中心轮询 /source_last（0.1s）
  → build_prompt（注入记忆 / 情绪指引 / 历史）
  → llama-server 生成
  → 解析 [TOOL:回复/表情/搜索/报错/结束]
  → 下桥清洗 _sanitize_reply（复读删 / 工具闭合 / 非法清理）
  → 输出队列（TTS 播报 + 表情动作）
```

**三个关键设计决策**（均有踩坑记录背书）：

- **桥 = wait 哨兵（读后清空）**：单消费者 `GET /take` 原子「返回+置 wait」，天然不重复、无连接状态、断线零成本。替代了 SSE 长连接（socket 超时后无法续读、维护成本高、推即弃无重放）与游标增量（三件套复杂度远超单消费者场景）。
- **L0 哲学**：`history` = LLM 真实看见过的对话，桥只负责传递，不做加工。
- **SSE 模式仍保留**用于「一推多收」场景（TTS / 搜索页面）。

## 双记忆系统

| | 上文记忆（写） | 长期记忆（读） |
|--|--------------|---------------|
| 方向 | 压缩归档 | 检索召回 |
| 机制 | L0 原文 → L1 摘要 → L2 主题 → L3 日常 → L4 永久，PPL 过滤（Cowan 工作记忆 4±1 依据） | BERT 四轴分类（领域/规模/时间/评价）+ SQLite 标签过滤 + bge 余弦精排 |
| 触发 | history > 10 条批量处理最老一轮 | 每轮 LLM 回复完成立即处理最新一轮 |

**核心哲学**：拒绝「无分类能力的 RAG」。长期记忆先分类（重心位移 → 只走主移动一步 → 目标空间），再检索——避免多轴同时偏移跳到无数据组合。当前命中结果尚待注入下一轮 prompt（下一步）。

## FACS 情绪引擎（神经科学依据）

三层架构（全部可溯源到论文）：

1. **杏仁核层（低通路）**：LeDoux 双通路，信号特征检测 `tense / orient / approach / relax`，半衰期 0.3–2.5s。
2. **皮层层（高通路）**：Ekman 7 基本情绪 + neutral，embedding 语义匹配。
3. **VAD 累积 → FACS → Live2D**：13 通道 VAD，各情绪独立半衰期（采用 8–12 岁少女参数），Calvo 2016 可见阈值，sigmoid(k=12) 非线性映射，卡通放大系数（上半脸 1.5–2.0×）。

**五组情绪映射**：来源 = 首级分类（输入线/输出线），单一归属不叠加——直接建「我的情绪」原型组，1:1 进 VAD，避免查表叠加堆出 sad。

## 弹幕打分与交互

- **10 正 + 5 负启发式特征**，全部来自 6 篇实证论文（FlirtGen 15k 条 / Chen 1.5k 条 / Library Hi Tech 1.9k 条 等），非拍脑袋。
- **三阈值弹夹架构**：秒发 0.30 / 组合 0.30 / 丢弃 0.11；已存弹夹攒够组合阈值自动发射。
- **发射冷却 + 待发射队列**：三把锁职责分离（`_state_lock → _fire_lock → _sent_lock`），规避死锁。
- 688 条真实弹幕实测：秒回 10.5% / 进弹夹 1.7% / 丢弃 87.8%。

## 训练系统

**流水线**：PT（持续预训练 v1–v53）→ 身份 SFT → 工具身份 SFT → 工具链 GRPO → 续写 GRPO（v3a）→ 搞事 GRPO（v9d，当前产出 v11b）。

**关键工程**：

- **Lomo 全参优化器**：在 3090 Ti 24GB 跑通 8B 全参微调（省去 Adam 状态，权重+梯度+优化器同驻显存）。
- **GRPO**：`GROUP_SIZE=2`，golden×20 / 采样×0.01 / UL 复读×40；`enable_thinking=False` 必须走 `apply_chat_template`。
- **持续预训练分层写入法**：身份 / 交互可分阶段独立写入，几乎不互冲、不灾难性遗忘（GRPO 反之会入口冲突）。
- **数据铁律**：`{裸问题}<think>三段推理[解析/身份+欲望/决策]</think>{回答}`，手工逐条打磨，禁止脚本批量生成。
- **17 阶段训练方案** + 83 条叙事数据（P1 公理 → P2 行为 → P3 情感 → P4 抽象）。
