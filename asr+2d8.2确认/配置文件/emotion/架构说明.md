## 五组情绪映射体系（2026-08-08 定稿，来源=首级分类）

**核心设计（拉姆拍板）**：不做映射表（检测对方情绪→查表→叠加容易堆出 sad），改为**直接建"我的情绪"原型组**——文本按来源进对应组，检测出情绪后 1:1 进 VAD，**单一归属不叠加**。

```
来源 = 首级分类（两个端点天然隔离，方向判定只在自己那一侧内部细分）：
  LLM 回复线 (/output) → 硬币说的 → 三选一 classify_subject
      ├─ 我说我 → self-self 原型组 (9类) → SPK_OUT_SELF  1:1 (out_me ×1.8)
      ├─ 我说你 → i-to-you 原型组 (9类) → SPK_OUT_YOU   1:1 (out_you ×0.8)
      └─ 我说别人 → (老逻辑) dist 转移
  ASR 输入线 (/facs) → 别人说的 → 二选一 is_about_you
      ├─ 你说我 → told-me 原型组 (9类) → 1:1 直接进 VAD (你 ×1.4, 无映射表)
      └─ 你说别人 → (老逻辑) SPK_TO_L_NORMAL 传染
```

**三组新原型（都在 emotion 目录，键=我的情绪，值=触发句）**：

| 文件 | 场景 | 设计依据 |
|------|------|---------|
| `self_self_prototypes.py` | 我说我 | 1:1（我好害羞→shy、我好难过→sad…）；shy/worried/hurt 3类新增 |
| `i_to_you_prototypes.py` | 我说你 | 1:1（你太过分了→angry、你真好→happy…）；fear→scared、surprise→surprised |
| `told_me_prototypes.py` | 你说我 | 逐组心理学审校（见下） |

**told-me 心理学审校要点**（每句只归一个情绪，避免叠加出 sad）：
- happy：被夸（你好可爱/你真棒…）
- shy：被夸外貌/被注视/**被表白**（"我喜欢你"→害羞不是开心！）
- worried：**被怀疑闯祸/负面结果预告**（你是不是干了什么坏事/你麻烦大了）——不是"对方状态不好"（那是关心对方）；依据：预期性焦虑=负面预期+不确定性
- angry：被攻击/被冒犯（你太过分了/你敢这样对我）；"你根本不在乎我"是对方控诉→归 hurt
- hurt：被控诉/被辜负/被嫌弃（你对不起我/你真烦/你走开）
- sad：被冷落/被抛弃（你都不理我/你不爱我了）
- fear：被威胁（你死定了/你完了）；"你别过来"删（那是威胁者的话）
- surprise：vtuber 场景（你上热搜了/有人给你刷了艘火箭/你就是硬币？）
- contempt：对方自大/吹牛（我可是专家）；原"就你？/你也就这样"是对方轻蔑我→归 hurt/angry

**检测函数**（facs_engine.py，同款 softmax×5×conf）：
- `detect_self_emotion(text)` — self-self 原型
- `detect_you_emotion(text)` — i-to-you 原型
- `detect_told_me_emotion(text)` — told-me 原型

**接入点**：
- `output_engine.process()`：先 classify_subject → "我"用 detect_self_emotion / "你"用 detect_you_emotion / "他"用老 detect_speaker_emotion
- `facs_server._process_frame()`：atk=True（你说我）→ detect_told_me_emotion 直接 1:1 进 VAD（**SPK_TO_L_ATTACK 映射表已删除**）；atk=False → 老 SPK_TO_L_NORMAL 传染

**输出侧 VAD 转发（2026-08-08 修复）**：pipeline `_do_send` 拿 LLM 回复 → 清洗 → 提取纯文本（thought + [TOOL:回复] arg，方案B）→ POST 18768/output。之前 LLM 回复从未转发 VAD，输出侧两组映射永远不会触发。

**contempt 方向判定**：从 ASR 进来时"我可是专家"判"说你"→told-me contempt 组 / 判"说别的"→NORMAL contempt→contempt 1.0——双路都出轻蔑，无需担心。

## 说话模式演绎（2026-08-04 新增, 话语级事件驱动）

说话模式判定: `_isSpeaking()` = 手动开关 `_speakMode` || 发声状态 `_vocalizing`(有音量, 20:01 改)

三轴事件系统（每"触发下一句"一次: 新音频开始 / 静音0.2s预触发 / 手动按钮）:

| 轴 | 参数 | 触发 | 方向三态 | 基准幅度 | 弹簧 |
|----|------|------|----------|----------|------|
| 转头 | ParamAngleX | 每句 | 30%回正 / 49%反向 / 21%同向 | 18.4°±30% (同向=增量半量) | 慢弹簧 k2.8/c3.3 (~1.8s) |
| 歪头 | ParamAngleZ | 每句 | 50%回正 / 35%反向 / 15%同向 | 12°±30% (同向=增量半量) | 同慢弹簧 |
| 点头 | ParamAngleY | 每句一次抬-落 | 情绪只定方向(正抬/负低) | 18°±30% | k=9×(1/ts²), ts=0.5s±20% |

- **方向三态** `_swingDirChange3(spring,dir,base,backProb)`: 回基线(慢弹簧走回正面, 本身即肢体语言) / 反向(完整幅度) / 同向(从当前位置增量半基准)
- **点头**: 每句触发一次"抬-落"动画, 完成后停住不循环; 情绪只影响方向(NOD_UP_EMOTIONS: happy/surprise/neutral 抬, 其余低)
- **躯干跟随**: **仅转头带动躯干** `ParamBodyAngleX = 转头pos × 0.25`(同号, 研究: 说话小幅度躯干跟随15~30%); **点头/歪头的躯干跟随不做**(模型灵活度原因, 18:42 决定)
- 调试日志: 仅"触发下一句"(20:16 精简, 其他调试日志全删)

## 发声/静音状态机（2026-08-04 用户定稿: 倾听→首句→延续判断）

三态: 倾听(默认) → 有语音=首句进说话模式 → 说话中延续性判断:

| 条件 | 动作 |
|------|------|
| 有音量(`_lipSmoothVal > 0.01`) | `_vocalizing=true` 说话模式, 重置静音计时 |
| 静音 ≥200ms (`GAP_TRIGGER`) | **预触发"下一句"** (新点头+新转头, 先发制人防过幅) |
| 预触发后 400ms 内(总静音<600ms)有声音 | 确认, 正常走"下一句"动作 |
| 总静音 ≥600ms (`GAP_SENTENCE`) | **打断回基线**切倾听: `_vocalizing=false` + 弹簧回正(target=0) + `_endNod()` |
| 音频结束/新音频 | 新音频开始=首句/换向(`_initSwing` or `nextSentence`) |

- **SILENCE_RMS=0.01 实测标定**: 真停顿(标点)底噪 0.000~0.001(真空) / 弱音段(150-240ms 气声)中位 0.015~0.03 / 说话区中位 0.03~0.07 → 阈值取 0.01 (20:12 用户确认, 数据见 measure_rms3.py)
- 停顿实测: TTS 标点停顿 420~1200ms (CosyVoice 逗号反而比句号长, 故不区分逗号/句号, 统一按"下一句"处理)

## 说话眼神（2026-08-04, 眨眼+VOR补偿）

- **眨眼频率**: 说话 3~6s 随机(动画角色不宜太快) / 倾听待机 2~10s; 轻蔑不眨通用眼(自己管理); 页面加载即启动循环(不依赖WS, WS listen兜底)
- **眨眼切换盯/不盯**: 每次眨眼闭眼时 `_gazeMode = rand<0.7?'track':'loose'`(闭眼120ms掩盖切换)
  - **track(盯前方70%)**: 眼珠反向补偿抵消头动(VOR)——`ParamEyeBallX = -转头pos×0.032 + 扫视漂移`、`ParamEyeBallY = -点头pos×0.032 + 扫视漂移`; 歪头不补偿; 扫视漂移每0.5~1.5s换目标(±0.15, 像扫视你/观察五官)
  - **loose(随头30%)/非说话**: `delete _actionOverrides.ParamEyeBallX/Y` 清残留回表情/漂移值(目光随头不修正)
- **EYE_VOR_K=0.032 标定来源**: 轻蔑v1 扭头25°(ParamAngleX:25) + 偷瞄眼珠 ParamEyeBallX:-0.80 → 0.80/25=0.032 (模型实测校准)
