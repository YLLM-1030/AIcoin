# 一次性表情动作系统

> 2026-08-05 定稿 · puppet_live2d_v2.html
> **6 组表情**：认真、wink(4变体)、开心(2变体)、spin(2变体)、转头(2变体·独立轻蔑状态机)、担心(2变体)

---

## 一、总架构

### 控制开关

表情动作触发时自动关三个开关，结束后恢复触发前状态：

| 开关 | 作用 |
|------|------|
| `_vadControl = false` | VAD 不控制身体 |
| `_blinkControl = false` | 不眨眼（继续轮询） |
| `_cyclePaused = true` | 循环 timer 延后但不切换 |

### 动画机制（两层）

- **姿态(肢体/面部)**: phases → `_emitTarget` → 弹簧通道
- **眼球(override)**: phases 可选 `override` 字段 → `_actionOverrides` 直接写（轻蔑状态机复刻用）

### 阶段 = `{ params, kc, dur, override? }`

```js
{ params: { ParamBrowLY: -0.2 }, kc: { ParamBrowLY: { k: 45, c: 13 } }, dur: 350 }
// override 字段可选: 直接写 _actionOverrides, 不走弹簧
{ params: {}, override: { ParamEyeBallX: 0.5, ParamEyeBallY: 1.0 }, kc: null, dur: 1000 }
```

- `null` = 回倾听基线（_emoteBase，表情播放前快照）
- 打断机制：playEmote 开头清上次残留 + 检测弹簧偏离则前插归位阶段

## 二、认真（情绪收敛）

**表演依据**（表演课/动画原理）：认真 = "收起"的过程，不是瞬间表情。皮克斯表情转变：**眉毛先动（第一动点）→ 眼睑/嘴落后半拍 → 头再沉**。wikiHow：眉轻微压低但不内斜（内斜=生气）；嘴面无表情；克制比夸张更像认真。

**时间线（7 段，总 3.45s）**：

| 段 | 时间 | 参数目标 | kc(k) |
|----|------|----------|-------|
| A 预备·视线聚焦 | 0~0.2s | EyeBallX/Y→0（眼珠收敛）、BodyAngleY→+3（前倾） | 眼珠 90 / 身 35 |
| B 眉毛先压 | 0.2~0.55s | BrowLY/RY→-0.2（压眉，平直不内斜） | 眉 45 |
| C 眼睑眯+嘴收紧 | 0.55~0.95s | EyeLOpen/ROpen→0.6、MouthForm/MouthOpenY→0 | 45 |
| D 头沉+前倾 | 0.95~1.35s | AngleY→-9（低头）、BodyAngleY→+6（前倾） | 35 |
| E 保持·克制 | 1.35~2.85s | 全静止（目标不变） | — |
| F1 眼睑先回 | 2.85~3.1s | EyeLOpen/R→null（回基线） | 70 |
| F2 全部回正 | 3.1~3.45s | 其余全 null | 45/35/90 |

**注入数值规则**：
- 面部（眉/眼/嘴）按 `emotion/live2d_emotion_mapping.md` 各情绪表幅度（×2 标准）
- 肢体（头/身）**×3 起手**（2D 角色肢体不明显，需放大才看得出；对照文档 sad 低头 6°、care 前倾 6°）
- 低头 AngleY 用负（248 行按钮：AngleY -15=低头）；前倾 BodyAngleY 用正（253 行：BodyY+15=前倾）

## 三、wink（4 变体，俏皮）

**表演依据**：
- UCLA eyelid kinematics 论文：眨眼闭合有 **overshoot（过冲=用力闭眼）** 的生理依据；**睁眼比闭眼慢**（Mueller 提肌）
- wordln wink 分解：完整 wink = 快闭（0.1s）+ 停顿 + 睁开（0.1~0.3s）
- 动画原理：歪头 = **anticipation（预备动作）**；回弹 = overshoot/ease
- 神经学（biologyinsights）：wink = **神经肌肉分离**——单侧精确闭合、**对侧完全放松**（另一只眼绝不动）

**4 变体**（WINK_VARIANTS 映射，按钮固定）：
| 按钮 | dir | same | 头 | 身（模型实测方向） | 眨眼侧 |
|------|-----|------|----|--------------------|--------|
| wink 同左 | +1 | true | 左歪 | 左倾（跟随） | 左眼 |
| wink 同右 | -1 | true | 右歪 | 右倾（跟随） | 右眼 |
| wink 反左 | +1 | false | 左歪 | 右倾（对抗） | 左眼 |
| wink 反右 | -1 | false | 右歪 | 左倾（对抗） | 右眼 |

**时间线（6 段，总 2.02s）**——眨眼 = 闭上 + 保持闭眼 + 睁眼 三过程：

| 段 | 时间 | 身体(AngleZ) | 眨眼侧眼 | 说明 |
|----|------|-------------|----------|------|
| P1 歪头慢蓄力 | 0~0.5s | 0→30°（k35） | 不动 | anticipation |
| P2a 闭上·压极限 | 0.5~0.7s | 30→36°（k45） | k300 快闭冲 -0.3 | 闭眼速度峰值 |
| P2b 保持闭眼前80% | 0.7~0.956s | 保持 36° | 保持闭 | 压缩持续 |
| P2c 后20%·回弹启动 | 0.956~1.02s | 36→0（k90） | 仍闭 | **极值点=保持闭眼 80% 处** |
| P3 睁眼·回弹 | 1.02~1.62s | 回弹（k90） | k80 慢睁（比闭眼慢） | 回弹=压缩 130% |
| P4 慢回正 | 1.62~2.02s | k35 衰减 | 睁完 | 嘴角收回 |

**关键数值**：保持闭眼 320ms（80% = 256ms 处回弹开始）；压缩 = 200+256 = 456ms；回弹 600ms = 131%。

**注入数值规则**：肢体（头±30/36°、身±8/10°）放大到 2D 夸张级；眨眼过冲 -0.3（用力闭眼）；眨眼侧 = 头低的那侧（左歪眨左眼）。

## 四、踩坑记录（按严重程度）

1. **fidget（待机微动作）写错层**：待机微动作写进了 `_actionOverrides`（覆盖层）→ 步骤 4 直接覆盖表情输出，wink 歪头被 ±3° 待机歪头钉死（"脖子不动、身体动"）。**待机类动作必须叠加 `_renderParams`（步骤 2 同款），覆盖层只给说话/倾听/眼神用**。
2. **脏弹簧 pos**：`_springs` 是全局持久状态，表情打断后残留脏 pos；参数从"指数平滑"切到"弹簧"时若 `_springs` 已存在会用脏 pos → 对侧眼跳（EYE-JUMP 日志破案：springL=pos=0.485 残留）。修复：归位阈值 0.05° + 不给没动过的参数设 kc。
3. **眨眼只眨一半**：阶段 dur < 弹簧到位时间（临界阻尼 95% 到位 ≈ **4.7/√k**，不是 3/√k）→ 眨一半被下一阶段拉回。修复：dur ≥ 到位时间 或 k 加大。
4. **BodyAngleZ 方向**：模型实际方向与按钮标注相反（标注 BodyZ+15=右倾，实际+15=左倾）→ 同左/反左互换。**方向类参数必须用户实测确认，不信按钮标注**。
5. **残留目标快照**：playEmote 快照 `_emoteBase` 时若上次表情被打断，残留目标被当基线 → delta=0 幅度变小。修复：playEmote 开头先 `_emoteRestore()`。
6. **瞬移（违反物理）**：弹簧 pos 硬回基线=瞬移。修复：前插**归位阶段**（弹簧走回基线再开始动作）。
7. **睁眼比闭眼快**：最初 P3 睁眼 k 比闭眼 k 大——生理上睁眼慢（Mueller），wink 睁眼 k80 < 闭眼 k300。
8. **对侧眼微收 0.8**：wink 时另一只眼动了（神经学错误，wink=对侧完全放松）→ 删。
9. **归位阈值 0.3 太粗**：脏 pos 偏移 0.29 不触发归位 → 阈值改 0.05。

## 九、踩坑记录

1. **fidget写错层** → 待机用 `_actionOverrides` 覆盖表情输出。修复: 叠加 `_renderParams`。
2. **脏弹簧pos** → 全局残留导致对侧眼跳。修复: 归位阈值0.05°。
3. **眨眼只眨一半** → dur < 4.7/√k。修复: dur ≥ 到位时间。
4. **BodyAngleZ方向相反** → 模型实际方向≠按钮标注，必须用户实测确认。
5. **自回归模型"理解"是负资产** → 说"抄"就一行不改地搬, 不要"改进"。轻蔑状态机抄了6次才对: 每次自作聪明改结尾/改弹簧/加概率全错, 最后一次纯复制3分钟完成。
6. **3.5倾听+0.15压平所有眼睛差异** → VAD活动时每帧 eyeOpen+0.15, sad_v2 0.4→0.55看不出。修复: 注释掉, 只保留前倾+歪头。
