# mini_coin 项目约定

## 训练规范

### LoRA 叠加
- 每阶段在上一阶段的 adapter 上继续训练
- LLaMA-Factory: `adapter_name_or_path: 上一阶段checkpoint路径`
- 同一个 output_dir 不能两个进程同时写

### 参数准则
- r=16, alpha=48, lora_target=all (Qwen3 all linear layers)
- 训练时必须带完整 SOUL prompt (推理用同一个)
- constant lr > cosine (小数据集需要持续更新)
- grad_accum=2, 不要大(8会导致更新太少)
- save_steps 设小一点, 多个 checkpoint 遍历选最优

### loss 目标
- Roast 行为: loss ~2.3-2.5
- 基座 loss 2.81 (作为参照)
- loss < 1.5 = 过拟合(复读机)
- 不信任平均 train_loss, 要看 per-step 曲线

### 训练/推理一致性
- 训练数据格式: sharegpt conversation
- dataset_info.json 需要 system_tag, user_tag, assistant_tag
- 同一个 SOUL prompt 在训练和推理中使用
