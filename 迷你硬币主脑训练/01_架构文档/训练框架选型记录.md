# mini_coin 项目记忆

## 训练
- **框架**: 纯PyTorch，不用LLaMA-Factory（fp32 upcast OOM）
- **优化器**: bitsandbytes.optim.AdamW8bit，A800 80GB实测33.7GB
- **显存计算**: 模型bf16(16.4G) + 梯度bf16(16.4G) + 优化器8bit(~16.4G) + 激活(~5G) = ~54G，实测33.7G（CUDA内存池重用）
- **等效学习量公式**: LR × epochs / 样本数
  - P1S1基准(1条): 8e-6 × 20 / 1 = 1.6e-4 → loss 0.74 ✓
  - 泛化(N条): 总等效量 1.0-2.0e-5 → loss 0.6-1.2
- **Loss目标**: 背诵0.4-0.8 / 泛化0.8-1.2 / 模式学习1.5-2.5 / 过拟<0.3
- **磁盘**: 每阶段存完即删 `shutil.rmtree`，80G足够
- **打包**: tar+源文件需双倍空间，不如scp -r直接传

## 模型链路 (Ollama WSL)
- 主脑: neko-v7:latest = Qwen3-8B P4S4_v7 Q8_0 (8.2B, 8.1GB, 40K ctx)
- 眼睛: neko-eye:latest = Qwen2.5-VL-7B abliterated Q8_0 (7.6B, 7.54GB, 128K ctx)
- 弹幕: 由主脑兼任（架构决策：不单独部署小模型）
- Ollama版本: 0.30.0-rc31, 路径: ~/bin/ollama
- GPU: RTX 3090 Ti 24GB, CUDA 13.3

## 模型部署方法
- **GGUF转换**: llama.cpp convert_hf_to_gguf.py (从Gitee镜像clone)
- **Ollama导入**: Modelfile FROM gguf路径 → ollama create
- **abliterated模型**: 优先pull ollama.com官方版；国内pull失败则从ModelScope下safetensors+本地转GGUF
- **ModelScope**: pip install modelscope → snapshot_download

## Abliteration
- 优先搜社区现成版（huihui-ai系列），别从零写
- 搜索顺序: HuggingFace → Ollama → ModelScope
