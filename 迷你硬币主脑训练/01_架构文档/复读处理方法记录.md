# mini_coin 工程笔记

## AI Perseveration（发疯/复读）已知处理方法

### 根因
Qwen3-8B 有已知的 repetition bug（Issue #1611），在以下条件下放大：
1. 输入总线扁平格式（非标准 user/assistant 交替）→ 8B 模型解析不了
2. "你最近说过"自指循环 → 上一轮幻觉喂回下一轮
3. 参数设置不当 → repeat_last_n 太大、presence_penalty 太高
4. 视觉 OCR 文字重复注入 prompt → 模型误认为"事实"

### 解码参数推荐（针对 Qwen3-8B）
- temperature: 0.8
- repeat_penalty: 1.15
- repeat_last_n: 64（默认值，不要改大）
- presence_penalty: 0.0（关掉，和 Qwen3 冲突）
- frequency_penalty: 0.3
- top_p: 0.9
- 长期方向：升级到支持 DRY sampling 的版本

### Neuro-sama 对比
- 据传用 ≈2B + q2_k 量化，比 Qwen3-8B 小 4 倍
- 性格在权重里（微调），prompt 只写"当前场景"
- 视觉经专用 CV 模型压缩为结构化文本，不灌原始 OCR
- 整体架构：分层（性格层→API约束层→执行层）
