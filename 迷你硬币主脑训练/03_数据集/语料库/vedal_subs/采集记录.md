
```powershell

for bvid in bvids:
    import subprocess
    subprocess.run(['python', 'get_vedal_subs.py', '--bvid', bvid])
"
```

## 踩坑记录

### 1. B站 API 限流
B站 API 有严格的频率限制（返回 `-799`）。
- **解决**: 每次请求间隔 8~15 秒随机，被限流后等待 30 秒重试
- 脚本已内置自动重试逻辑

### 2. Cookie 必须
字幕接口 `/x/player/wbi/v2` 需要 `SESSDATA` cookie，否则无法获取字幕信息。
- 从浏览器 F12 → Application → Cookies → `bilibili.com` → `SESSDATA` 复制
- 写入脚本的 `SESSDATA` 变量

### 3. WBI 签名问题
B站部分新接口需要 WBI 签名算法。目前字幕接口用 Cookie 方式可访问，不需要额外实现 WBI。
- 如果后续失效，需要实现 `bilibili-api-python` 库的 WBI 签名

### 4. 输出路径问题
PowerShell 默认工作目录是 `C:\WINDOWS\system32`，脚本相对路径会保存到 system32 里。
- **解决**: 脚本已固定输出到 `C:\Users\Autogram-coin\Desktop\新建训练\vedal_subs\`

### 5. YouTube 方案放弃原因
原计划从 Vedal 的 YouTube 频道 (`@Neurosama`) 获取英文字幕，但：
- YouTube 对非浏览器请求有严格反爬（需要完整的 cookie 集，包括 HTTP-only）
- Neuro-sama 视频多含游戏音频，YouTube 自动生成字幕质量不可靠
- B站搬运版本已有高质量中文字幕，优先采用
