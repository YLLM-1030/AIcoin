## 监控指标

| 指标 | 健康范围 | 警告信号 |

| 训练 loss | 平稳下降 | 突然暴跌 >50% → 过拟合 |

## 如果效果不对

1. **Loss 不下降**: 提高 LR 到 `1e-6`，增加 1 个 epoch
2. **Loss 下降太快**: 降低 LR 到 `0e-6`
3. **输出变机械**: 回退到上一个检查点，减少 1 个 epoch 重来
4. **完全不对**: 从 `ckpt_p4s2` 重新开始，LR 减半
