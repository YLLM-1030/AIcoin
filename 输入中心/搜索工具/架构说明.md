# 搜索工具架构说明

> search_server.py + web_search.py · 2026-08-07  
> 端口: 18775

## 一、整体功能

独立搜索工具，供管线执行队列"搜索"任务调用，也可手动使用。
支持两种搜索引擎切换 + 搜索历史保存 + SSE 实时推词 + 结果/完成桥上桥。

## 二、文件

| 文件 | 说明 |
|------|------|
| `search_server.py` | HTTP 服务 (ThreadingHTTPServer) + Web 页面 + SSE |
| `web_search.py` | 秘塔搜索封装 (chat/completions 端点, conciseSnippet) |
| `search_history.json` | 搜索记录（开启保存模式时写入） |
| `pipeline_searches.json` | 管线搜索记录（关闭轮询后不再写入，仅作历史存档） |

## 三、API

| 端点 | 方法 | 功能 |
|------|------|------|
| `/` | GET | 搜索页面 |
| `/api/search` | POST | 执行搜索 (手动/SSE结果触发) |
| `/api/search_history` | GET | 查看手动搜索历史 |
| `/api/queue_search` | POST | 管线推送搜索词 (SSE推送到页面) |
| `/api/queue_sse` | GET | SSE 长连接 (EventSource) |

### POST /api/search

```json
{
  "query": "搜索词",
  "source": "metaso" | "deepseek",
  "save": false,
  "prompt": "DeepSeek提示词模板，{query}替换"
}
```

- `prompt` 仅在 `source=deepseek` 时生效，秘塔不使用
- `save=true` 时写入 `search_history.json`
- 返回: `{"result": "结果文本", "saved": false}`

### POST /api/queue_search

管线推送，触发 SSE 推词到搜索页面：

```json
{"query": "搜索词"}
```

### GET /api/queue_sse

SSE 长连接。新连接自动获取最近一次推送（`_sse_push` 缓存）。
收到 `{"query": "..."}` 后页面自动填框搜索。

## 四、前端

```
搜索框 [秘塔/DeepSeek下拉] [⚙提示词配置] [搜索按钮]
保存开关 ☐ 保存搜索记录
结果区
搜索结果上桥 [18000-18009/关] [保存]
搜索完成 done [18000-18009/关] [保存]
🔗 管线搜索任务 (折叠面板, 历史记录)
📋 历史记录 (可折叠, 手动搜索记录)
```

- ⚙: 展开 DeepSeek 提示词编辑器 (存 localStorage)
- 搜索结果上桥：搜完后 POST `{source:"搜索返回", text:结果}` 到选定桥
- done 上桥：搜完后 POST `{source:"tts_done", text:"done"}` 到选定桥

## 五、搜索引擎

| 引擎 | 实现 | 说明 |
|------|------|------|
| 秘塔 | `web_search.py` → `/api/v1/chat/completions` | conciseSnippet, key 内置 |
| DeepSeek | `deepseek_search()` → api.deepseek.com | 可编辑提示词，key 内置 |

- 搜索返回自动清洗 `[[数字]]` 引用标记

## 六、SSE 推送机制 (同 TTS 模式)

```
管线 POST /api/queue_search
  ↓
_sse_queues (queue.Queue 列表) → 所有 SSE 连接逐个 put
  ↓
页面 EventSource.onmessage → 填输入框 → doSearch()
```

- `ThreadingHTTPServer` (daemon_threads=True) 支持多并发
- `_sse_push` 缓存最近一次推送，新连接可立即获取

## 七、管线接入

管线执行队列消费者：
1. `cmd=="搜索"` → `POST /api/queue_search {"query":arg}` → SSE 推词
2. 搜索页面自动搜索 → 结果上桥 → done 上桥
3. 消费者轮询 `EXEC_BRIDGE_PORT` (默认 18003) → `tts_done=done` → pop
4. 工具返回模块配 endpoint=结果桥 → prompt 自动注入搜索结果
