## 🔴 当前要做：BERT 头（过渡版，启发式先行）

### 1. addressee 判断：这句话在跟谁说？
```
启发式特征（训练 BERT 前先用）:
  - 含"主播""硬币""拉姆"等称呼 → 大概率@我
  - 含"你""妳"第二人称 → 可能@我
  - 含"大家""你们""谁" → @群体，非定向
  - 纯陈述无指向 → 自言自语/氛围
  - 回复其他人的弹幕 → @别人

输出: @me / @group / @others / @self
```

### 2. reply_desire 打分：多想回这条？ 0-1
```
特征（来自论文调研）:
  + 提问(?) → +0.3
  + 脑洞/假想 → +0.2
  + 表达不同意见 → +0.2
  + 正面情绪 → +0.1
  + 第二人称"你" → +0.1
  - 纯陈述无问号 → -0.2
  - 只有表情/单字 → -0.3
  + 熟人/粉丝牌 → bonus（后续加）

输出: 0-1 分数
```

### 3. 两者联合
```
addressee × reply_desire → 最终得分:
  @me   × 0.8~1.0  → 几乎必回
  @group × 0.5~0.9 → 看内容
  @others × 0.2~0.5 → 一般不回（除非特别想插嘴）
  @self  × 0.1~0.3 → 自言自语气氛组
```

## 🔴 当前要做：总分架构实现

### 热度计算
```
heat = 过去10秒弹幕数 + 过去30秒SC/礼物权重
冷: 0-2条/10s → 阈值低
温: 3-6条/10s → 阈值中
热: 7+/10s → 阈值高
```

### 三阈值（已确认：硬币话痨参数 v2）
```
触发阈值 = 0.30  → 单条分≥0.30 → 立即开火（弹幕+弹夹全发18005）
理会上限 = 0.30  → 弹夹总分≥0.30 → 自动发射
理会阈值 = 0.11  → 低于0.11丢弃，0.12起进弹夹
```

### 弹夹逻辑
```
弹幕进来 → BERT打分 →
  ├─ 分 < 理会阈值 → 丢弃
  ├─ 分 ≥ 触发阈值 → 弹夹+本条 → 立即发射到18005 → 清空弹夹
  ├─ 中间 → 进弹夹
  │     └─ 弹夹总分 ≥ 理会上限 → 自动发射
  └─ （如果连续N条都@others → 触发"抢注意力"模式）
```
