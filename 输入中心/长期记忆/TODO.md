## 🔴 记忆自动进库（2026-08-09 记，晚点做）

**现状**：记忆库（memories.db）没有自动进库——新对话/新信息不会自动写入长期记忆，需要人工/脚本导入（import_memories.py）。

**目标**：接一个 DeepSeek API，自动：
1. **自动改写内容**：把原始对话/输入改写成"记忆条格式"（纯事件叙述，参考 `长期记忆文件内容存放/伪造记忆/人际关系/01_拉姆.md` 的格式）
2. **按标签识别丢进记忆库**：用标签引擎（tag_engine.py / memory_tag_prototypes.py）分类（人物/知识/新闻/关系等），写入 memories.db

**关键点**：
- 记忆条格式铁律：纯事件叙述（谁做了什么、说了什么、结果），不渗透个人感受/评价；检索时是纯文本，标签是推算用的（[重要度|时间||分类]）
- 接入点候选：pipeline 的 trigger_retrieval / 上文记忆压缩归档时，把新信息喂给 DeepSeek API → 改写 → 分类 → 入库
- 费用可控：DeepSeek API 便宜；只在对话有"值得记的事"时调用（可先启发式判断或节流）

**前置**：确认 DeepSeek API key 和调用方式（搜索工具 search_server.py 已经接了 deepseek-chat，可参考其调用方式 L33）
